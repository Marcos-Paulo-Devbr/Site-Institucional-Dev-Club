## 📖 Sobre o projeto

Site institucional da **DevClub**, plataforma de ensino de programação criada por **Rodolfo Mori**.

O conceito visual é uma **caixa de ferramentas** que se abre: cada módulo do curso (HTML & CSS, JavaScript, React, Node.js...) é apresentado como uma "ferramenta" que resolve um problema real de quem está aprendendo a programar. A experiência é guiada por **scroll**, com um plano de fundo animado que reage ao movimento do usuário e vai "montando" o logo da marca conforme a página é percorrida.

> 🎯 Objetivo: apresentar a DevClub de forma moderna, envolvente e fácil de entender — mesmo para quem nunca programou.

---

## 🛠️ Tecnologias utilizadas

| Tecnologia | Onde é usada |
|---|---|
| **HTML5** | Estrutura semântica de todas as seções do site |
| **CSS3** | Estilização, layout responsivo, animações e paleta de cores da marca |
| **JavaScript (Vanilla)** | Interatividade: scroll reativo, contadores animados, carrosséis, acordeão de FAQ, terminal animado |
| **Canvas API** | Animação de plano de fundo reativa ao scroll (efeito de partículas / glifo se formando) |

> 💡 React e Node.js aparecem no site como parte da grade de tecnologias **ensinadas no curso** (ícones de stack), não como tecnologias usadas na construção deste site institucional em si, que é feito em HTML, CSS e JS puros.

## ✨ Principais seções e funcionalidades

- 🚀 **Hero** com ilustração de astronauta e efeito de caixa de ferramentas se abrindo
- 🖱️ **Background reativo ao scroll**, montando o glifo/logo da DevClub conforme a página avança
- 🧩 **Módulos do curso** em carrossel (HTML & CSS, JavaScript, React, Node.js e mais)
- 💻 **Terminal animado**, simulando comandos digitados em tempo real
- 🔢 **Contadores animados** (números que sobem ao entrar na tela)
- 🎠 **Carrosséis** de módulos, projetos e empresas parceiras
- ❓ **FAQ em acordeão**
- 🗣️ **Depoimentos** de alunos e empresas
- 📬 **Newsletter** para captação de leads
- 🖼️ **Pasta de exemplos**: 7 projetos reais que mostram na prática o que um aluno da DevClub é capaz de construir

## ▶️ Como rodar localmente

Como é um site estático (HTML, CSS e JS puros), não é necessário instalar nada.

```bash
# 1. Clone o repositório
git clone <url-do-repositorio>

# 2. Entre na pasta
cd devclub-site

# 3. Abra o index.html no navegador
# (ou use uma extensão como "Live Server" no VS Code)
```
